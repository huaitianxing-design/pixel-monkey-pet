# 🐵 Pixel Monkey Pet 像素猴子

一只 64×64 纯像素风的桌面/网页养成宠物。像早年 QQ 宠物一样养一只猴子——喂食、陪玩、哄睡、洗澡，照顾得好它才会慢慢长大，从**幼猴 → 少年猴 → 成年猴 → 戴皇冠的猴王 👑**。

本仓库包含两个版本：

| 版本 | 位置 | 说明 |
|---|---|---|
| 🌐 **网页版** | [`monkey-web.html`](./monkey-web.html) | 单文件，双击用浏览器打开即玩，零依赖 |
| 🖥️ **桌面挂件版** | [`desktop/`](./desktop/) | Electron 工程，可打包成透明置顶的 macOS 桌面挂件 |

---

## 🌐 网页版（最简单）

直接双击 `monkey-web.html`，用任意现代浏览器打开即可。存档保存在浏览器 localStorage 里。

## 🖥️ 桌面挂件版（macOS）

透明无边框、始终置顶的桌面小挂件，可收起成边缘小图标。

```bash
cd desktop
npm install
npm start          # 本地运行
npm run dist       # 打包成 macOS App（arm64）
```

打包产物在 `desktop/dist/` 下。macOS 首次打开若提示“无法验证开发者”，右键图标选「打开」确认一次即可。

> 桌面版为 ad-hoc 签名，`entitlements.plist` 提供了 Electron 运行所需的权限。

## ✨ 特性

- **纯像素风**：64×64 canvas 逐像素绘制，无贴图资源
- **灵活待机动画**：东张西望、挠头、甩尾巴、眨眼、原地小跳，几乎一直在动
- **成长系统**：成长速度取决于照顾质量（心情权重最高），不喂不哄就长得很慢甚至停滞
  - 每天照顾 1~2 次，约 5 天少年猴 / 12 天成年猴 / 25 天猴王
  - 完全放养则永远长不大
- **状态系统**：饱食、心情、精力、清洁四维，随时间自然衰减
- **主动播报**：状态偏低时主动提醒；启动/定时主动播报天气（上海，open-meteo）
- **互动**：点击猴子触发随机小动作（挥手/跳跃/跳舞/点头）

## 🛠️ 技术栈

- 纯 HTML + Canvas + 原生 JavaScript（无框架）
- 桌面版：Electron + electron-builder
